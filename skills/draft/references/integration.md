# Draft Integration

把新材料整理成 draft 的一部分，同时保留“文章仍在生长”的状态。

## 先判断材料的作用

结合目标 draft，判断新材料更接近哪种关系：

- 对已有判断的补充或更准确的说法
- 新的论据、例子或经验材料
- 对已有内容的反例、限制或不同方向
- 尚未回答的问题、猜想或矛盾
- 与中心相关但暂时找不到位置的旁支

这个判断只用于决定放置方式，不要在正文里机械添加“补充”“反例”等标签。

## 放置与整理

- 与已有内容语义重复时，合并成更完整的一段，保留两边各自有信息量的部分。
- 能自然进入已有小节时放在相关段落附近，不一律追加到文末。
- 一个方向已经出现多段材料时，可以建立或调整小节标题；不要为每个新片段创建标题。
- 新材料改变了相邻段落的先后关系时，可以在局部重排。除非用户明确要求，不进行整篇重构。
- 暂时无法安放但仍与文章相关的内容，放在文末 `## 尚未安放`；后续有了结构再移动，不把它伪装成正式结论。

## 轻量文字处理

可以删除命令外壳、寒暄、重复开头和只依赖当前对话的指代，修正明显语病，并让句子脱离对话后能够理解。保留第一人称、语气强弱、疑问、猜测和限定词。

不要为了衔接而补写用户没有表达过的因果、论据或结论。两段之间尚不存在可靠关系时，可以并置或保留问题，不写一个看似顺畅但改变语义的过渡句。

## 矛盾与不确定性

新材料与旧内容冲突时，先确认它们是否真的是互斥判断。不能确认时保留两边，并在合适位置写成尚待处理的张力或问题；不要擅自选择一边，也不要强行综合出新结论。

更新 `intent`、标题或标签只用于反映已经出现的文章方向。若方向仍不稳定，保留暂定措辞。`updated_at` 使用本地 ISO 时间，`created_at` 和 `draft_id` 不变。

完成前只复核本次修改及其必要上下文：新材料没有丢失，旧语义没有漂移，Markdown 结构仍有效，文件仍保留 `_` 前缀。
