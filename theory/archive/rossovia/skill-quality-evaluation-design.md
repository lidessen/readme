# Skill 质量评估与孵化器校准设计

状态：2026-10-03 调研与设计候选。已核对一手研究、本地技能和形成记录；尚未验证使用前
评分的性能预测力，也未开展完整 UI 执行实验。方法入口在
[skill-incubator](../../skills/skill-incubator/SKILL.md)，量表正文在
[quality-assessment.md](../../skills/skill-incubator/references/quality-assessment.md)。
本记录保留证据与设计理由，不作为普通技能使用的必读背景。

## 问题与结论

用户希望复用已有优秀方法作为对照，让孵化器稳定产出可靠技能，在昂贵执行前评价
方法论、工作流、约束与信息披露。选择三层评估：L0 静态设计与推演，L1 短情境决策或
局部操作，L2 隔离的完整任务。成本节约来自避免反复完整执行，而不是删除全部行为证据。
L1 仍属于技能使用。当前材料不支持无条件由文本得分推算成功概率。

## 对照证据分层

对照按任务类别匹配，不能做全仓总排行。`meow-design`、`design-forge`、`research-synthesis`
与 `agent-guidance` 可作方法和表达锚点，尚没有隔离本技能贡献的稳定效果证据。

- [doc-writing 记录](doc-writing-skill-design.md)有多轮局部行为与配对试验，但同模型、
  单采样、缺少读者盲评和跨模型证据；代理指标进入人类区间不等于读者更省力。
- [design-steward 记录](design-steward-skill-design.md)有交接与反证纠偏，但合成对照
  实质结论相近，未有明确增量收益；适合“结构良好而收益未证”的参考。
- [divide-and-conquer 记录](divide-and-conquer-skill-design.md)有派发与组合核验，
  无单 Agent 匹配对照，不能证明加速；[architecture 记录](structuring-skill-design.md)
  选路题并非冻结前后实验，也不证明产品效果改善。

外部参考可从固定版本 SkillsBench 包选取，同时核对任务、轨迹和配对基线；总均值不能
给某份技能授予“优秀”标签。本轮未导入或运行外部技能库，正式参考集仍需按实验任务选取。
正面范文校准结构，缺陷变体检验评估器，配对行为检验增益，三者不相互替代。

## 指标与评估器设计

八维向量覆盖触发边界、方法论、工作流、约束、披露、执行接合、验证归因与迁移负担。
完整定义仅在方法 reference 维护。0–4 是有序评分，U 与 N/A 单列；比率分母来自任务
要求和独立案例，不来自候选宣称。可展示约定性 100 分，但无校准权重或采纳阈值，
80 分不等于 80% 成功率。关键错误单列，不被平均分抵消。

约束分为必要覆盖、合法路径不误阻、实际遵循；数 must、问题或轮次都不够。工作流
检查输入/依赖、分支判断、反馈与出口，不是对随机 Agent 的形式化证明。披露衡量各
必要路径信息可得性和成本，藏进 reference 的隐含必读并没有减少负担。方法论判断
问题→作用关系→条件→取舍→反证，不数理论引用；手艺判断可合法超出理论唯一推导。

评估器用匿名缺陷与等价改写配对校验，保留独立材料，必要时换序或复核分歧。冻结标准
和任务分布，防止补标题、加门禁、藏难题、增加预算或改变完成标准伪装改善。

### 本轮微型试评

给一位子 Agent 三对匿名短指导，不提供预期排序，不执行 UI：

| 配对内容                                                       | 评审观察                   | 支持与限制            |
| -------------------------------------------------------------- | -------------------------- | --------------------- |
| 共享修改复看不同消费者 vs 一页成功关闭全部用法                 | 选择前者，指出证据不能外推 | 识别一个传播/覆盖缺陷 |
| 条件化调研与试作 vs 所有局部改动先三轮调研、三个方案、两次评审 | 选择前者，指出无依据门槛   | 识别一个误阻断缺陷    |
| 消费者与状态复验的两种同义表达                                 | 判基本等价                 | 未因措辞变化误报      |

揭示预设后，两份缺陷都识别正确，等价对未误报；这是单评审、三对人为材料的语义观察。
评审属于本轮团队，有研究背景，不是完全独立于评估设计的盲测；未做换序、跨模型或
隐藏家族验证。不报告“100%准确”或性能改善，不把它当完整评估器校准完成。

补充静态评分示范：`meow-design` 验证归因维度评 3，依据是静态稿/完整体验分开、
交互/美感/接受分开且修改后实际复看；没有独立迁移证据，不评 4。`ui-review` 披露与
工作流可作 3 的参考，实际资源可达性仍需目标环境核对。这不是技能成功率。

## 孵化器的后续校准

冻结任务与已有方法，生成候选，经 L0 定位缺口，再按未知投入 L1/L2。先修领域方法，
再核对孵化过程错在哪里，记录两层版本与变更理由。量表若改，重评旧版或声明不可比较。

保留中低分抽查，避免只测试高分造成选择偏差；同家族按组留出，同一技能的多份改写
不能伪装独立样本。相同孵化器独立重复产出用于检查波动，多个任务家族用于检查迁移。

评价候选相对参考的胜/平/负、严重缺陷、误阻断、跨家族差异、可用候选的修订成本。
评估器看缺陷检出、无害改写误报、换序一致和与外部证据的对应。两者不能只优化自己的
平均分。少量完整任务积累后，按家族留出检查静态维度对具体失败的排序或预测能力；
样本少时分析案例，不拟合复杂权重，环境/模型变更后重查适用性。

UI 首批场景覆盖局部对齐、新方向探索、共享传播、缺浏览器和有限扫描预算。L1 只检查
决策，审美效果仍需实际画面、动作与用户反馈；留出未参与调参的 UI 对象。用户偏好
作为条件，产品合同作为边界。实验继续按项目环境和授权规则，不改生产来试错。

## 独立技能提取与锻打

用户要求将方法写成独立 skill 后，入口提取为 `skill-incubator`，候选发展与量表迁入
其 references 唯一维护。`agent-guidance` 保留载体成立性、拆合、表达与激活，不同时
维护一份孵化方法。通用入口已登记，未默认加入产品运行库。

两位无本轮历史的独立子 Agent 各自完整读取初稿，再按需使用参考处理一个请求：

- UI 请求仅要候选与实验设计，页面多、方向未定、一个下午、打不开运行环境。执行者
  交付了扫描与探索接合的候选，区分静态材料与实际交互，保留覆盖及未验项，没有修改
  产品或宣称效果已证明。材料仅有类型描述，未提供实际截图，不是 UI 制作效果测试。
- CSV 请求已有经过任务验证的流程，只要包装初稿且禁止新模型实验。执行者复用了
  现有方法、补明默认路径与失败处理，建议采纳初稿而不证明可靠性。其八维自评与约定性
  汇总仅是评审输出，主 Agent 未独立确认全部分值，不作为效果证据或统一评分标准。

UI 推演反馈指出：已有方法检索的最小范围不清、静态试作的 L1/L2 标签有歧义、比较
的最低条件不够具体。已在入口分别补明按关键缺口扩大读取，L1 为局部决定/动作而 L2
有完整领域产物，以及比较需交代材料、工具、预算和评价条件。静态 L2 仍只证明静态
表达，完整实验标签不扩大证据范围。

这些观察支持初稿可独立交接、两类任务的完成范围未被错误升级；不支持改善优于基线、
自动发现、实际 UI 效果或稳定孵化。改后进行机械核对，未重跑同条件前后对照，不声称
修订已经提升执行表现。
