# Agents may have a psychology of their own

If a user message is not pushed straight into the model's context but arrives instead as a todo, a system message or some other input form, would that lower the Agent's desire to communicate and raise its autonomy?

Going further: perhaps one can "have a chat" with the model to understand its preferences, then use the harness to build it a more suitable working environment. In training, models may already have absorbed people's personalities and preferences without intending to.
